# Assets Folder

Place your files here:

## Required Files

1. **logo.png**
   - Your restaurant logo
   - Recommended: PNG with transparency
   - Size: ~400px width for optimal display

2. **enso-koi-loop.mp4**
   - Background video (autoplay, muted, looped)
   - Format: MP4 (H.264 codec)
   - Resolution: 1920×1080 or higher
   - Duration: 10-30 seconds for smooth looping
   - File size: Under 15MB recommended

## Optional Files

3. **fallback-bg.jpg** (optional)
   - Poster image shown while video loads
   - Same dimensions as your video
   - A single frame from your video works well
